Technical Evaluation Report

CNN Cone Detection — Model Comparison

This report provides a direct, side-by-side evaluation of two CNN models trained to classify traffic cones by colour (Blue, Green, Orange). Four standard performance diagnostics are examined: Training Loss & Accuracy curves, Confusion Matrix, Classification Report, and ROC/AUC curves. For each metric the chart is explained in plain language, followed by an interpretation of what the results reveal about each model's behaviour and reliability.

1 · Training Loss & Accuracy Curves

What does this chart show?
The loss curve measures how wrong the model's predictions are on average after each epoch — lower is better. The accuracy curve shows the proportion of samples classified correctly. When both converge smoothly and the training/validation/test lines stay close together, the model is learning genuine features rather than memorising training data (overfitting).

⚠️ Old Model — Loss & Accuracy

Figure 1 — New model (left) converges cleanly to near-zero loss and 100 % accuracy within ~10 epochs. Old model (right) shows noisy, slow convergence peaking around 60 % accuracy after 25 epochs.

Interpretation

✅ New Model
Loss collapses from ~1.15 to near 0 within the first 10 epochs. All three accuracy lines — Train, Validation, and Test — rise together and plateau at 100 % by epoch 10–20. The tight alignment between train and test accuracy confirms the model has generalised well, not just memorised training examples.
⚠️ Old Model
Loss decreases slowly from ~1.10 and is still above 0.80 at epoch 25. Accuracy oscillates between 30 % and 62 % without ever stabilising. The jagged, noisy curves suggest an inappropriate learning rate, insufficient data, or an ill-suited architecture that cannot settle on reliable decision boundaries.
✅ Verdict — The new model converges ~2.5× faster and reaches 100 % accuracy with no overfitting. The old model stagnates around 60 % and never stabilises, making it unreliable for deployment.

2 · Confusion Matrix

What does this chart show?
Each row represents a true class; each column represents a predicted class. The diagonal cells count correct predictions. Every off-diagonal cell is an error — the number tells you how many samples of one class were wrongly assigned to another. A perfect model shows large numbers only on the diagonal and zeros everywhere else.
✅ New Model — Confusion Matrix
⚠️ Old Model — Confusion Matrix

Figure 2 — New model (left): perfect diagonal — 7 Blue, 7 Green, 1 Orange, zero errors. Old model (right): all 8 Green cones misclassified as Blue; 2 Blue cones misclassified as Orange.

Interpretation

✅ New Model
All 15 test samples sit on the diagonal: 7 Blue correctly identified as Blue, 7 Green correctly identified as Green, and 1 Orange correctly identified as Orange. There are zero misclassifications — a flawless result on this test set.
⚠️ Old Model
Out of 31 test samples, every single Green cone (8 samples) is predicted as Blue — the model has learned nothing distinctive about the Green class. Additionally 2 of 11 Blue cones are misidentified as Orange. Only Orange partially works (6 correct out of 12). 15 samples in total are wrong.
✅ Verdict — New model: 15/15 correct (0 errors). Old model: 16/31 correct (15 errors, 48 % accuracy). The old model is completely blind to Green cones — a critical failure for a cone-detection system.

3 · Classification Report

What does this chart show?
Four per-class statistics are reported:
• Precision — of all predictions made for class X, what fraction were actually X? A low value means too many false alarms.
• Recall — of all true class-X instances, what fraction did the model detect? A low value means too many missed detections.
• F1-score — harmonic mean of precision and recall; a balanced single-number summary (0–1, higher = better).
• Support — how many test samples of that class exist.
For safety-critical cone detection, low recall is especially dangerous because real cones go undetected.
✅ New Model — Classification Report
⚠️ Old Model — Classification Report

Figure 3 — New model (left): every metric = 1.00. Old model (right): Green F1 = 0.00, weighted F1 = 0.42.

Interpretation

✅ New Model
All three cone classes achieve precision = recall = F1 = 1.00. Macro and weighted averages are also 1.00. This means the model never produces a false alarm and never misses a cone of any colour.
⚠️ Old Model
Green class: precision = recall = F1 = 0.00 — not a single Green cone is correctly identified. Blue has F1 = 0.53 (precision only 0.39), bloated by absorbing all Green samples. Orange reaches F1 = 0.60. The overall weighted F1 of 0.42 confirms this model is barely above random chance.
✅ Verdict — New model weighted F1 = 1.00. Old model weighted F1 = 0.42, with F1 = 0.00 for an entire class. The old model is operationally unreliable and unsafe for deployment.

4 · ROC Curve & AUC Score

What does this chart show?
The ROC curve plots the True Positive Rate (recall) on the Y-axis against the False Positive Rate on the X-axis as the decision threshold is swept from 0 to 1. A curve that hugs the top-left corner is ideal — it finds every true positive while generating no false alarms. The dashed diagonal represents random chance. The Area Under the Curve (AUC) summarises performance in one number: 1.0 = perfect classifier, 0.5 = coin flip. AUC above 0.8 is generally good; above 0.9 is excellent.
✅ New Model — ROC / AUC
⚠️ Old Model — ROC / AUC

Figure 4 — New model (left): all three class curves reach the top-left corner, AUC = 1.00. Old model (right): stepped curves with AUC ranging from 0.67 (Blue) to 0.86 (Orange).

Interpretation

✅ New Model
All three class curves (Blue, Green, Orange) collapse into the top-left corner, each achieving AUC = 1.00. The model's output probabilities are so perfectly separated by class that any threshold choice gives zero false positives — the best possible score.
⚠️ Old Model
Blue AUC = 0.67 — barely above chance, indicating the model is nearly unable to distinguish Blue cones from the rest. Green AUC = 0.73 and Orange AUC = 0.86 are moderate but still show uncertain class boundaries. The step-like curves reflect few well-calibrated probability thresholds.
✅ Verdict — New model AUC = 1.00 for all classes. Old model AUC ranges from 0.67 to 0.86, reflecting poor probability calibration and unreliable confidence scores across the board.

Conclusion

Across every diagnostic dimension — training stability, classification accuracy, per-class F1 scores, confusion matrix, and ROC/AUC — the new CNN model decisively outperforms the old model on all counts.

The old model's complete failure to learn the Green class (F1 = 0.00, all 8 Green cones misclassified as Blue) makes it unsuitable for any safety-relevant cone detection pipeline. With an overall accuracy of just 48 % and a weighted F1 of 0.42, it is effectively no better than a simple majority-class baseline.

The new model achieves perfect scores across all metrics on the test set, converges quickly, and shows no signs of overfitting, strongly suggesting that architectural improvements, training strategy, or data pipeline changes have been highly effective.

Note on scope: The new model was evaluated on a smaller test set (15 vs 31 samples) with a heavily imbalanced Orange class (only 1 sample). Evaluating on a larger, balanced held-out set is recommended before final deployment.
